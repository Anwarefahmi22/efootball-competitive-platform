# eFootball Competitive Platform

A competitive social platform for eFootball players: identity-first profiles, ranked play, community, live events, verification, and an in-platform economy — built as a monorepo with a FastAPI backend and a future Android client.

**Tech stack:** Python 3.11+, FastAPI, PostgreSQL, SQLAlchemy 2.0 (async), Alembic, Pydantic v2, JWT auth (bcrypt) · Android (Kotlin) client later.

> **Status:** Phase 1 of 8 — Core Identity (Users, Profiles, Authentication)
